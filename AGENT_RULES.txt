# STORYTELLER — ARCHITECTURE-SPECIFIC RULES FOR CODING AGENTS

## 1. FILE & DATA FORMATS (ZERO JSON / ZERO YAML / ZERO SQL)
1. NEVER use JSON (`encoding/json`, `JSON.stringify`, `JSON.parse`, `.json` files) anywhere in backend, frontend, config, or storage.
2. Book metadata (`books/<id>/data.txt`) MUST use plain-text `key: value` lines:
   - Allowed keys: `title`, `author`, `description`, `narrated` (`true|false`), `imageless` (`true|false`), `start` (`<scene_id>`), `cover` (`<relative_raster_path>`).
3. Story content (`books/<id>/story.txt` or per-chapter `<chapter_id>.txt`) MUST use plain-text structural headers and arrow transitions:
   - Headers: `chapter:`, `scene:`, `id:`, `image:`, `voice:`, `next:`, `end: true`, `text:`.
   - Choices: `Choice Label -> target_scene_id` (or `-> END`). Literal arrows in prose MUST be escaped as `\->`.
   - Single outgoing transitions MUST normalize to implicit `Dalej` (`next: <target>` or sequential same-file scene), never a single custom-labeled choice button.
4. Node Studio layout (`books/<id>/editor.txt`) MUST use `key: value` and `->` coordinates:
   - Viewport: `pan_x: <int>`, `pan_y: <int>`, `zoom: <float>`.
   - Nodes: `node: <scene_ref> -> <x>, <y>` snapped to `EditorGridSize = 24`.
5. Application settings (`saves/settings.ini`) MUST use INI sections (`[display]`, `[audio]`, `[library]`) with `key = value` pairs written atomically via `.tmp` + `os.Rename`.
6. Player progress (`saves/<book-id>.sav`) MUST use the custom Little-Endian binary format (`STSV\x01`):
   - Periodic audio playback position updates MUST patch bytes `[5..21]` in-place via `UpdateSaveAudioTimeInPlace` (`os.File.WriteAt`) without rewriting the file.

## 2. CLIENT-SERVER PROTOCOL (HTML-OVER-THE-WIRE, ZERO REST/JSON)
1. All UI mutations and commands MUST go through `POST /api/action` with `Content-Type: application/x-www-form-urlencoded`.
2. Never return JSON from `/api/action`. The server MUST:
   - Render an HTML chunk from `app/templates/*.tpl` and set `X-Target` (`#app`, `#workspace`, `#modals-root`, `#editor-context-panel`, or `none` with HTTP `204 No Content`).
   - Emit state updates and client commands exclusively via HTTP response headers (`X-Theme`, `X-Imageless`, `X-Imageless-Locked`, `X-UI-Scale`, `X-Audio-Speed`, `X-Auto-Choice`, `X-Auto-Strategy`, `X-Keep-Scroll`, `X-Reset-Canvas`, `X-Device-Mode`, `X-Toast`, `X-Native-Cmd`).
3. Client actions MUST be declared in `.tpl` via `action: <ActionName>` and `data-*` attributes (which `app/js/core.js` converts from `data-foo-bar` to form param `foo_bar`).
4. Batch node coordinates in `SaveEditorState` MUST be encoded as `positions: id1:x1,y1;id2:x2,y2`.
5. Every `POST /api/action` request MUST pass `validateSameOriginAction` (`Sec-Fetch-Site`, `Origin`, `Referer`).

## 3. TEMPLATE (`.tpl`), STYLESHEET (`.tss`) & JS BUNDLING DISCIPLINE
1. Edit ONLY source files in `app/templates/*.tpl`, `app/styles/*.tss`, `app/js/*.js`, and `app/icons/*.svg`.
2. NEVER manually edit `build/app/index.html`, `build/app/style.css`, or `build/app/app.js`. Always run `tpl.BuildApp` (`./build.sh` or `go test ./...`) after modifying `app/`.
3. `.tpl` compile-time security gates (`internal/tpl/tpl.go`) MUST NEVER be bypassed:
   - Forbidden tags: `<style>`, `<iframe/frame/frameset>`, `<object>`, `<embed>`, `<applet>`, `<base>`, `<foreignObject>`, inline `<svg>`, and inline `<script>` (only `<script src="/app.js">` is allowed).
   - Forbidden attributes: `style="..."`, `on*=` event handlers, `srcdoc`, `http-equiv`, and `javascript:`/`vbscript:`/`data:` URLs.
   - All icons MUST be standalone files in `app/icons/*.svg` referenced via `svg.class src: /icons/name.svg`.
   - Dynamic context values rendered via `-> var` or `"{var}"` MUST be HTML-escaped and NEVER undergo secondary `{...}` interpolation. Raw HTML (`-> html:var`) is allowed ONLY for `book.RenderSafeProseHTML` output.
4. `.tss` stylesheet rules (`internal/tpl/tss.go`):
   - Write indentation-based rules without `{}` or `;`.
   - Define theme/preview tokens in `app/styles/colors.tss` using `light-dark(lightVal, darkVal)` and `--var` references.
   - Wrap all device preview frame rules in `/* @dev-only-start */ ... /* @dev-only-end */` and template nodes in `-> if dev_mode` so production builds strip them completely.
   - When adding a new `.tss` or `.js` file, register it in `CSSModuleFiles` / `JSModuleFiles` (and `CSSPlayerModuleFiles` / `JSPlayerModuleFiles` if needed in standalone player mode) in `internal/tpl/bundle.go`.

## 4. UI, LAYOUT & INTERACTION INVARIANTS
1. Topbar visibility (`header.topbar#topbar`) is UNBREAKABLE:
   - `.app-root` MUST remain a 2-row grid (`grid-template-rows: auto 1fr`) with `#topbar` in row `1` (`z-index: 200`) and `#workspace` + `#modals-root` in row `2` (`z-index: 120`).
   - `.modal-backdrop` and `.scene-text-fullscreen-backdrop` MUST use `position: absolute; inset: 0` inside `#modals-root`, NEVER `position: fixed`.
   - `SwitchView` and `OpenBook` MUST close all open modals (`s.SceneTextModalID = ""`, `s.QRModalOpen = false`, etc.).
2. Visual geometry & controls:
   - Keep `border-radius: 0 !important` globally (`base.tss`), except circular node ports (`.node-input-port`, `.choice-output-port`), slider thumbs, and progress/notch pills.
   - NEVER use native `<select>` elements; always use `.custom-select` (`.custom-select-trigger` + `.custom-select-menu` + `.custom-select-option`).
   - NEVER add `border-bottom` or `text-decoration: underline` to `.topbar-tab` or `.top-action-btn` (only `.topbar` itself has `border-bottom`).
   - NEVER use up/down arrow buttons (`↑`, `↓`) to reorder scenes or choices; use 24px-grid canvas dragging (`data-node-drag-grip`) and wire ports.
   - Canvas node cards (`.timeline-node-card`) MUST stay read-only on the canvas (grip `⋮⋮`, title, choice labels, ports, `+ Wybór`); all text inputs and delete buttons belong in `#editor-context-panel`.

## 5. MEDIA, AUDIO POLICY, BOOK PACKAGING & GRAPH RULES
1. NEVER generate or synthesize audio samples:
   - Do NOT synthesize `.flac`, `.ogg`, or `.mp3` placeholder audio in Go code or during `CreateNewBook`.
   - Books default to `narrated: false` (no audio); when narration is enabled, only real user-recorded voiceover files are imported into `voice/`.
2. Strict media allowlist & magic-byte verification (`internal/book/media.go`):
   - Images: ONLY `.png`, `.jpg`, `.jpeg`, `.webp` (verify `\x89PNG`, `\xff\xd8\xff`, `RIFF....WEBP`). Strictly forbid `.svg` and `.gif` in book media.
   - Audio: ONLY `.ogg`, `.flac`, `.mp3` (verify `OggS`, `fLaC`, `ID3`/`\xff\xe0`). Strictly forbid `.wav`.
   - Reject any media file > 100 MB or containing HTML/XML/script signatures in the first 512 bytes.
3. All-or-nothing narration policy:
   - If `narrated: false`, clear all scene audio fields, omit `voice:` when serializing `.txt`, return HTTP `403` on audio requests, and render `#reader-progress-footer` instead of `#audio-deck`.
   - If `narrated: true`, emit a parser warning on every scene without a valid audio file.
4. Zero-copy external books & read-only `.stbook` packages:
   - Adding a book from local disk (`AddBookFromDisk`) MUST register its path in `settings.ini` (`ExternalBooks`) without copying files into `books/`.
   - `.stbook` / `.zip` archives (`b.IsPacked == true`) are strictly read-only; all mutators in `internal/book/mutator.go` and editor actions MUST refuse to modify packed books.
   - Production builds (`packageBooksForDist`) MUST pack source books into `dist/.../books/<id>.stbook` and never ship unpacked book folders.
5. Graph-driven ordering (no numeric filename prefixes):
   - Chapters and multi-file scenes MUST be ordered by BFS graph traversal from `StartSceneID` (`orderChaptersAndScenesByGraph`), never by `01_`, `02_` filename prefixes.
6. SSRF protection:
   - `DownloadBookFromURL` MUST block loopback (outside `go test`), private, link-local, multicast, and CGNAT IP ranges in `net.Dialer.DialContext` and cap downloads at 250 MB.

## 6. ZERO EXTERNAL GO DEPENDENCIES & NATIVE WINDOW HOST
1. `go.mod` MUST have zero external `require` dependencies (pure Go standard library only).
2. Native OS windows (`internal/gui/window_*.go`) MUST use:
   - macOS (`darwin && cgo`): Objective-C Cocoa + `WKWebView` with frameless `NSWindowStyleMaskFullSizeContentView` and hidden traffic-light buttons.
   - Windows (`windows`): Pure-syscall Win32 + `EmbeddedBrowserWebView.dll` (WebView2 COM vtables) and generated COFF `.syso` PE resources (`writeWindowsResourceSYSOForArch`).
   - Linux (`linux`): Chromium/Edge `--app` mode with `zenity`/`kdialog` file pickers.
3. Never spawn a native window or OS file dialog when `ST_NO_WINDOW=1` or under `go test`.
